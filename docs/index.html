01 / How it works

From a sentence to a checked video.

Your tools, your models, your machine. Foresight brings the method; Crystal Ball brings the eyes.

Know your tools NOW

Lists what your Hermes can reach: image, voice, video and sound tools, MCP servers and media apps. Each one gets a tool card.

Plan the video SOON

Pick a video type and type one sentence. Foresight writes the script and the scene plan, and an independent critic reviews both before anything is made.

Make it SOON

Each scene is made with your own tools, with time and cost shown first. Then one MP4 is assembled with captions, in vertical, wide or square.

Check every take NOW

Crystal Ball checks images, audio and video with the checks that apply. Anything it can't check says so. A PASS is a floor, not approval.

03 / Tool cards

Works with tools it has never met.

No adapters to write. A tool being installed is not proof it works; one small real test is.

Discover

Finds the tools on your machine without running them.

Draft a card

Records how to call the tool, what it takes in and what it gives back.

One tiny test

Shows the expected cost and wait. You confirm once. The output is checked by Crystal Ball.

Remember

Saves measured time, cost and quality notes. Correct, disable or forget a card any time.

04 / Start local

A toolkit you can own.

Python 3.11+, ffmpeg and ffprobe. Crystal Ball 1.2 installs with it. No bundled models or media.

Standalone

TERMINALLinux / macOS
python3 -m venv .venv
.venv/bin/python -m pip install git+https://github.com/gregoryhorn/foresight
.venv/bin/foresight inventory
.venv/bin/foresight card templates
.venv/bin/foresight check render.mp4
Windows PowerShell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install git+https://github.com/gregoryhorn/foresight
.\.venv\Scripts\foresight.exe inventory
.\.venv\Scripts\foresight.exe check render.mp4
