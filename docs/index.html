Start with your own tools

From presence to evidence.

Inventory

Discover local tool presence without executing tools. Cached host metadata stays scoped; presence is not permission.

Tool cards

Keep data-only mappings and their limits. One disclosed, confirmed tiny test. Unknown delivery never means blind retry.

Media checks

Retain exact-byte evidence using Crystal Ball. Check images, audio and video with applicable rules and visible omissions.

A toolkit you can own.

Python 3.11+, FFmpeg and ffprobe. From a local checkout:

python -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/foresight inventory
.venv/bin/foresight card templates
.venv/bin/foresight check ~/Media/example.mp4 --report-dir ~/Reports/example
Windows PowerShell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\foresight.exe inventory

The foresight Hermes tool exposes inventory, starter cards and media checks. It performs no automatic generation, installation or qualification.

Technical PASS is not creative approval. Missing senses remain visible. No provider configuration or model download is performed.
